## Agent skills

### Issue tracker

Issues are tracked as GitHub issues in `Widyasa/netrasense`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles map to the same label strings: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: `CONTEXT.md` at the repo root plus `docs/adr/`. See `docs/agents/domain.md`.
